# IntrusionDetection-System

## 📌 Overview

🔍 Cyber threats are increasing rapidly, and traditional systems struggle to detect unknown attacks.

💡 This project introduces an **Anomaly-Based Intrusion Detection System (IDS)**  
that leverages Machine Learning to detect suspicious network behavior.
