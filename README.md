# Intrusion Detection System using Random Forest

## Overview

This project detects network intrusions using the KDD Cup 99 dataset and a Random Forest Classifier.

## Features

- Data preprocessing
- One Hot Encoding
- Random Forest Classification
- Streamlit Web Interface
- Real Time Attack Prediction

## Attack Classes

- Normal
- DoS
- Probe
- R2L
- U2R

## Accuracy

75.86%

## Technologies

- Python
- Pandas
- Scikit-Learn
- Streamlit
- Matplotlib
